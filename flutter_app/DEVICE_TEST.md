# دليل اختبار النموذج الأولي على جهاز Huawei MatePad 11.5 PaperMatte
# Device Testing Guide: Marsa Handwriting Prototype (Phase 0.3)

تم تصميم هذا النموذج الأولي خصيصاً ليتم اختباره على جهاز **Huawei MatePad 11.5 PaperMatte** (يعمل بنظام HarmonyOS 3.1 بدون خدمات Google Play، مع قلم Huawei M-Pencil الجيل الثاني أو الثالث الذي يدعم 4096 مستوى حساسية للضغط).

---

## 1. التثبيت والتشغيل عبر ADB (Build & Sideload)

### متطلبات الربط:
1. تفعيل **خيارات المطور (Developer Options)** على الجهاز اللوحي:
   - اذهب إلى: **الإعدادات (Settings) > حول الجهاز اللوحي (About Tablet)**.
   - اضغط على **رقم الإصدار (Build Number)** 7 مرات متتالية حتى تظهر رسالة "أنت الآن مطوّر".
   - ارجع إلى: **الإعدادات > النظام والتحديثات > خيارات المطور (Developer Options)**.
   - فعّل **تصحيح أخطاء USB (USB Debugging)**.
2. وصّل الجهاز اللوحي بالكمبيوتر عبر كابل USB-C، واختر نمط نقل الملفات واقبل رسالة تأكيد مفتاح RSA على شاشة التابلت.

### التحقق من اتصال الجهاز:
افتح سطر الأوامر (PowerShell أو Terminal) ونفّذ:
```bash
adb devices
```
يجب أن يظهر جهازك برمز تعريفي وحالة `device`.

### بناء وتثبيت التطبيق مباشرة:
من المجلد `d:/Projects/Marsa/app`:
```bash
# بناء نسخة التصحيح (Debug APK)
flutter build apk --debug

# تثبيت التطبيق على الجهاز اللوحي
adb install -r build/app/outputs/flutter-apk/app-debug.apk

# تشغيل التطبيق على الجهاز اللوحي
adb shell am start -n com.marsa.clinic/com.marsa.clinic.marsa_app.MainActivity
```

بدلاً من ذلك، يمكنك تشغيله في وضع المراقبة المباشرة:
```bash
flutter run -d <device_id>
```

## 2. ما يجب اختباره والتحقق منه (Test Checklist)

### أ. قراءة مستويات الضغط الحقيقية للقلم (Stylus Pressure)
1. قرّب قلم Huawei M-Pencil من الشاشة دون لمسها:
   - يجب أن يُظهر مربع الفحص العلوي (Debug HUD): `نوع الجهاز: stylus (hover)`.
2. المس الشاشة برفق بالقلم:
   - تحقق من ظهور قيمة `قيمة الضغط` (مثل `0.120` إلى `0.350`) والشريط اللوني يتحرك.
3. اضغط بقوة أكبر تدريجياً:
   - تحقق من تدرج القيمة حتى تقترب من `0.800` - `1.000` وأن عرض الخط يزداد تدريجياً على الشاشة.
   - **الحد الأدنى المقبول**: يجب ألا تكون القيمة `0.000` دائماً أثناء استخدام القلم الحقيقي.

### ب. زاوية الميل (Stylus Tilt)
1. أمِل القلم بزاوية حادة مع الشاشة ولاحظ تغير خانة `زاوية الميل` بالدرجات (°).

### ج. رفض راحة اليد بالبرمجيات (Palm Rejection)
1. ضع بطن راحة يدك (Palm) على الشاشة أثناء الكتابة بقلم M-Pencil.
2. تأكد من أن خطوط القلم ترسم بانسيابية دون ظهور نقاط أو خطوط عشوائية ناتجة عن لمس اليد.
3. تأكد في الـ Console من ظهور رسالة رفض اللمس:
   `[InkCanvas PalmRejection] Discarded touch event while stylus is active`

### د. زمن الاستجابة والانسيابية (Latency & Responsiveness)
1. اكتب عبارات عربية سريعة وتوقيعات طبية.
2. قيّم ما إذا كان هناك أي تأخير بصري ملحوظ بين سن القلم وظهور الحبر على شاشة PaperMatte.

### هـ. الأدوات والحفظ/الاسترجاع
1. بدّل بين ألوان القلم الثلاثة (أسود، كحلي، أحمر).
2. اختبر سماكات الخط المختلفة (رفيع 2.0، متوسط 4.5، عريض 8.0).
3. اختبر أداة الممحاة (Eraser) ومسح الأجزاء المكتوبة بسلاسة.
4. اختبر التراجع (Undo) والإعادة (Redo).
5. اضغط على زر **حفظ الملاحظة**: تأكد من ظهور إشعار بالمسار المحلي الناجح.
6. اضغط على زر **مسح اللوحة** (مع تأكيد الحوار)، ثم اضغط زر **استرجاع آخر حفظ** للتأكد من استعادة الخطوط تماماً.

## 3. مراقبة سجلات القلم عبر ADB Logcat (Live Sensor Logging)

لمشاهدة قيم الحساسات فورياً من سطر الأوامر أثناء الكتابة:
```bash
adb logcat -s flutter
```
ستظهر سجلات توضح أخذ العينات بدقة:
```
[Stylus-Down] kind=stylus | pressure=0.2315 | tilt=14.2° | pos=Offset(420.5, 310.2)
[Stylus-Move] sample=10 | kind=stylus | pressure=0.6840 | tilt=15.1°
[Stylus-Up] kind=stylus | final pressure=0.0000 | tilt=12.0° | total samples=48
```

## 4. كيفية استخراج وتصدير ملف الخطوط المحفوظ (Export Stroke JSON)

يتم حفظ الملف داخلياً في مسار التطبيق:
`/data/data/com.marsa.clinic/app_flutter/marsa_ink_test.json`

لسحب الملف إلى جهاز الكمبيوتر لفحصه:
```bash
adb pull /data/data/com.marsa.clinic/app_flutter/marsa_ink_test.json ./exported_test_stroke.json
```
