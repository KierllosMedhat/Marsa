# دليل نشر منصة مرساة الموحدة على Vercel (All-in-One Next.js)

تم توحيد كافة أجزاء منصة **مرساة** (الموقع العام + الخادم الخلفي API + بوابة فلاتر للطبيب والاستقبال) في مشروع **Next.js** واحد في جذر المستودع (`Root Directory`).

---

## 1. هيكل المشروع الموحد

| المسار | الوظيفة |
| :--- | :--- |
| **`/`** (`src/app/page.tsx`) | الموقع العام للعيادة، تقويم حجز المواعيد التفاعلي، واختبار القلق النفسي (GAD-7) |
| **`/portal`** (`public/portal/`) | تطبيق فلاتر الإكلينيكي المدمج (بوابة الطبيب + بوابة الاستقبال) |
| **`/api/*`** (`src/app/api/*`) | الخادم الخلفي المتكامل (تسجيل الدخول، تشفير AES-256، سجلات المرضى، الجلسات، المواعيد) |
| **`flutter_app/`** | الكود المصدري لتطبيق فلاتر (لبناء تطبيق الأندرويد/التابلت أو تحديث `/portal`) |

---

## 2. خطوات النشر على Vercel (مشروع واحد فقط وبضغطة زر)

لا تحتاج إلى أي خوادم خارجية (لا Render ولا Railway) ولا تحتاج إلى تعديل أي إعدادات معقدة:

1. ارفع التعديلات إلى GitHub:
   ```bash
   git push
   ```
2. افتح لوحة تحكم [Vercel](https://vercel.com/) واضغط **Add New... > Project**.
3. اختر مستودع `Marsa`.
4. سيتعرف Vercel تلقائياً على أن المشروع هو **Next.js** في المجلد الرئيسي (`./`):
   - **Framework Preset**: `Next.js` (تلقائي)
   - **Root Directory**: `./` (الافتراضي — لا تقم بتغييره)
   - **Build Command**: `npm run build` (تلقائي)
5. اضغط **Deploy**!

---

## 3. الروابط بعد النشر على Vercel

بمجرد انتهاء البناء (يستغرق أقل من دقيقة واحدة)، ستحصل على رابط واحد يجمع كل شيء، مثلاً `https://marsa-clinic.vercel.app`:

* **موقع العيادة للمرضى وحجز المواعيد**:  
  `https://marsa-clinic.vercel.app/`
* **بوابة الطبيب وموظف الاستقبال (Flutter Web Portal)**:  
  `https://marsa-clinic.vercel.app/portal`
  * دخول الطبيب: `doctor@marsa.clinic` / `DoctorPass123!`
  * دخول الاستقبال: `receptionist@marsa.clinic` / `ReceptionPass123!`
* **نقطة فحص الخادم الخلفي (API Health)**:  
  `https://marsa-clinic.vercel.app/api/health`
